# Keluarga Madi 👨‍👩‍👧‍👦

Private family chat app — Madi, Maya, Tia, Mia & Ria.

Built on [Tencent Cloud Chat](https://www.tencentcloud.com/products/im) (free plan), hosted free on GitHub Pages. Login with your own UserID + UserSig — no passwords stored on the server.

## Features

- 💬 Real-time group chat, WhatsApp-like: chronological order, timestamps, online/offline status
- 🔄 Auto-refresh every 15 seconds — no page reload, keyboard stays down
- 📱 Android app (APK) — see [Releases](https://github.com/kusmadi82/keluarga-madi/releases)
- 🔒 Private group — only members with a UserSig can read messages
